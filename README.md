# 📧 Spam Email Classifier

A Machine Learning project to classify emails as **Spam** or **Not Spam** with high accuracy.

## 🚀 Features

- **Level 1**: Basic ML classifier with web interface
- **Level 2**: Gmail integration with OAuth (coming soon)
- **Level 3**: Real-time classification & browser extension (coming soon)

## 📊 Model Performance

| Metric | Score |
|--------|-------|
| Accuracy | ~97% |
| Precision | ~95% |
| Recall | ~94% |
| F1 Score | ~95% |
